## 1.0.0 — 2026-10-22

- Six local stdio MCP tools covering health, models, reference images, asynchronous video generation, task status, and downloads.
- Private per-call configuration loading with environment overrides and API-key redaction.
- Explicit model/duration defaults, reference validation, actionable API errors, and no automatic POST retry.
- Streaming downloads with size/deadline limits, credential-safe redirects, atomic writes, and no overwrites.
- Portable CLI help/version and offline verification; optional read-only live/Codex checks.
- Regression tests, Node.js CI, English/Chinese documentation, MIT license, and contribution/security guidance.
